AI Data Insight Builder

학교 시스템 엑셀(.xls)을 올리면 코드가 정확히 계산하고, AI가 쉬운 보고서로 해석해 줍니다.

🔒 앱 잠금 해제

`.env`에 설정한 8자리 이상 비밀번호를 입력해야 앱을 사용할 수 있습니다.

인증 완료 (사용 가능)

1. 엑셀 파일 업로드

확장자가 .xls인 개설강의 파일을 선택해 주세요. 파일은 서버 디스크에 저장되지 않고 메모리에만 잠시 보관됩니다.

2. 파일 진단 결과

아직 업로드된 파일이 없습니다.

주의·경고 목록

    열별 빈칸 현황

    3. 분석 선택 또는 직접 질문하기

    AI가 추천한 분석을 고르거나, 궁금한 내용을 직접 질문하면 pandas가 계산해 줍니다. (원본 행은 AI에 보내지 않습니다.)

    4. 계산 결과 (pandas 직접 계산)
